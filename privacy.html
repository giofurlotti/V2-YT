Privacy Policy

Last updated: 27 July 2026

Giorgio's Dashboard is a personal, single-user dashboard built and used by one person (Giorgio Furlotti) to track fitness, health, nutrition, caffeine, and finance data, including data from the WHOOP API. It is not a public product or service, and it is not used to collect or process data belonging to anyone other than its owner.

What data is used

Depending on which page is open, the dashboard may read and store:

  • WHOOP data (recovery, sleep, workouts, cycles, profile, body measurements) via the WHOOP API, using an access token obtained through WHOOP's OAuth flow.
  • Manually entered health, fitness, hydration, caffeine, and finance data.

Where data is stored

Data is stored in the browser's local storage and, for cross-device sync, in a private Supabase project that the owner controls directly. No data is sold, shared, or made available to any third party, advertiser, or analytics service.

WHOOP data specifically

WHOOP access and refresh tokens are stored only in the browser's local storage and in the owner's private Supabase project, used solely to display the owner's own WHOOP metrics inside this dashboard. Access can be revoked at any time from the Health page ("Disconnect") or from WHOOP's own account settings.

Data retention & deletion

Data persists until manually cleared from local storage, deleted from the Supabase project, or disconnected via the app. There is no separate retention period beyond the owner's own use of the dashboard.
